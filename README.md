# CountryWars

Мод для **Minecraft 26.3 (Fabric)**, добавляющий глобальную экономику, случайные
ивенты и систему стран с жителями, наймом и войнами.

> ⚠️ Статус: **первая публичная сборка (1.0.0)**. Код проверен статически
> (`javac`, валидация JSON), но полная сборка Gradle выполнялась только
> на стороне пользователя — в среде разработки не было JDK 25 и доступа к Maven.
> Если при сборке возникнут ошибки — пришлите лог, правки будут быстрыми.

## Возможности

### 🛒 Магазин-обменник
- Полноэкранный GUI `/shop` с вкладками «Покупка» и «Продажа».
- Все предметы игры подтягиваются из реестра и сохраняются в `shop.json`
  с ценой по умолчанию 1/1 изумруд; для ключевых предметов цены заданы вручную.
- Поиск по названию, пакеты 1 / 8 / 16 / 64, листание кнопками ▲▼.

### 🎰 Ивенты
- Автоматически раз в 30 минут — каждому игроку свой ивент.
- Вручную `/event` с общим кулдауном 10 минут.
- Полноэкранная рулетка с замедлением перед стартом.
- Настройка в `events.json`: `handler` + параметры (эффект, мобы, предметы,
  TNT, лава, бонус с руды, музыка).
- `manualScope` в `config.json`: `"SELF"` (по умолчанию) или `"ALL"`.

### 🌍 Страны
- Палка-выделитель задаёт территорию двумя точками.
- Создание страны: название, цвет и символ флага, описание.
- GUI страны: население (жители в загруженных чанках).
- Нападение: ≥ 35 жителей и население не менее чем в 3 раза больше, чем у врага.
- Война: рассылка всем, волна разбойников у защитников, военный ивент.
- Команды: `/shop`, `/event`, `/country` (алиас `/strana`) → `wand`, `create`,
  `info`, `attack`, `join`, `leave`, `list`.

## Установка

1. Установите **JDK 25** и проверьте: `java -version`.
2. Соберите мод:
   - Windows: `gradlew.bat build`
   - Linux/macOS: `chmod +x gradlew && ./gradlew build`
3. Готовый файл — `build/libs/countrywars-1.0.0.jar`
   (файл `-sources.jar` не нужен).
4. Положите `.jar` в папку `mods/` **и клиента, и сервера**.
5. Установите зависимости: **Fabric API 0.166.0+26.3** и **Loader 0.20.1+**.

## Конфиги

Все файлы лежат в `config/` и редактируются без перекомпиляции:

- `shop.json` — цены покупки/продажи по предметам.
- `events.json` — список ивентов: `handler` и параметры.
- `config.json` — общие настройки, в т.ч. `manualScope`.
- `README.md` внутри архива — те же шаги и описание конфигов.

## Известные ограничения

- Полная сборка Gradle в среде разработки не выполнялась.
- Не подтверждены по документации и могут потребовать правок при первой сборке:
  `StreamCodec.ofMember`, `Registry.get(Identifier)` / `getValue`,
  `Level.getEntities(null, AABB, Predicate)`, `BlockState.blocksMotion()`,
  `ServerPlayer.sendSystemMessage(Component, true)`, конструктор `EditBox`.
- Колесо мыши в магазине не поддерживается — только кнопки ▲▼.
- Для войны на сервере должен быть включён PvP (`pvp=true`).
- Часть названий ивентов из ТЗ заменена заглушками; остальные добавляются
  в `events.json` без перекомпиляции.
